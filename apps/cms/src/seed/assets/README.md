# Pack visuel de prototype

Ces images ont été générées par IA pour peupler l’environnement local et
valider le rendu du site public dans la direction artistique de
`standalone(1).html`.

Elles sont importées automatiquement par `pnpm seed:demo`, redimensionnées en
JPEG par le seed puis référencées par les contenus Payload. Chaque média reste
marqué `isDemo` et porte une mention de droits dans la médiathèque.

Avant toute mise en production, l’administrateur doit remplacer ou valider
chaque visuel avec Africa Ingénierie, puis renseigner des textes alternatifs
correspondant exactement aux photographies définitives.
